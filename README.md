# 🎲 Dice Game GUI using Python

A fun and interactive **2-player Dice Game** built with **Python** and **Tkinter GUI**. Players take turns rolling a virtual dice, and the winner is decided based on the highest roll.

> ✅ No external images or assets needed  
> ✅ Built in one file with Python only  
> ✅ Lightweight, fast, and beginner-friendly project

---

## 🖥️ Features

- 🎮 Two-player turn-based gameplay
- 🎲 Random dice rolling using `random.randint()`
- 🖤 Minimal black-themed GUI using `tkinter`
- 🎯 Result display: Winner or Tie

---

## 🚀 How to Run

1. Make sure Python is installed:
   ```bash
   python --version
   ```

2. Save the code in a file named:
   ```
   dice_game_gui.py
   ```

3. Run the script:
   ```bash
   python dice_game_gui.py
   ```
